Modulo: Tu primera API


Haz clic y mira la consola (F12)

¿Que va a pasar?

Cuando pulses el botón, ocurrirá esto:


  1. JavaScript enviara una solicitud a superheroapi.com
  2. la API respondera con datos en formato JSON.
  3. Veras los datos en la consola del navegador.
  4. si hay error tambien aparecera en la consola.
