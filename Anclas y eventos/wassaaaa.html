¿Qué va a pasar?

Cuando pulses el botón, ocurrirá esto:

  1. JavaScript enviará una solicitud a: superheroapi.com
  2. La API responderá con datos en formato JSON
  3. Verás los datos en la Consola del Navegador
  4. Si hay error, también aparecerá en la consola
